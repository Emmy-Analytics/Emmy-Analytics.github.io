PROJECT 01 · DATA ANALYTICS

Alfamart POS Transaction Data Analysis

Exploring transaction data quality, anomalies, and operational risks in POS data.

TYPE Academic Study Case
TOOLS Python · Pandas · EDA
STATUS In Progress

01 · OVERVIEW

What was the problem?

The project explores POS transaction data to identify issues that may affect data reliability, transaction accuracy, promotion control, and operational monitoring.

02 · BUSINESS QUESTION

How can POS data be used to improve transaction accuracy and operational control?

03 · DATA PREPARATION

What did I find in the data?

120,000 Missing Member ID records
1,483 Negative quantity transactions
9,000 Pre-opening transactions
Inconsistent Payment method label

04 · ANALYSIS

Four areas of investigation

Promotion & Member Patterns

Examining JSM purchasing patterns and member identification.

Quantity Anomalies

Reviewing negative and extreme quantity patterns.

Payment Method Consistency

Checking consistency across payment categories.

Transaction Timing

Investigating logical errors such as transactions before store opening.

05 · RECOMMENDATIONS

Turning insights into action.

06 · CONCLUSION

Better transaction data supports better decisions.

This analysis highlights how POS data quality can affect promotional control, cashier operations, reporting consistency, and system reliability.

The proposed improvements focus on stronger transaction controls, standardized master data, and simple validation rules that can help reduce avoidable data issues at the point of transaction.

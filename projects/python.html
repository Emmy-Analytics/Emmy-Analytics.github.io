PROJECT 04 · PYTHON

Python Library Management System

A console-based library system built to practice Python programming fundamentals, data handling, and business rules.

TYPE Academic Study Case
TOOLS Python
FOCUS Programming Fundamentals

01 · CONTEXT

Turning programming fundamentals into a working system.

This project applies Python fundamentals to a simple library management scenario, covering member registration, borrowing, returning, stock updates, and fines.

02 · USER FLOW

One menu connects the whole borrowing process.

Member

Register and manage member data.

Borrow

Select a book and create a loan record.

Return

Calculate late days and applicable fine.

Stock

Update book availability after transactions.

03 · FEATURES

Small features, connected by clear rules.

Member Management

Add and manage library member records.

Book Borrowing

Record borrowing transactions and update available stock.

Return & Fine

Calculate late days and apply the defined fine rules.

Data Management

Organize information using Python data structures and files.

04 · PYTHON LOGIC

Business rules translated into Python logic.

Check book availability

A borrowing transaction can only continue when stock is available.

Update stock

Borrowing decreases available stock, while returning restores it.

Calculate fine

Late returns trigger the configured daily fine rule.

From syntax to system thinking.

Building this project helped connect Python fundamentals with practical business rules and transaction logic.
